## 3. Error Analysis and Verification Protocol

An experimental run is only considered a valid confirmation of QGT metrics if it eliminates the following systemic errors:

1. The Aerodynamic Control: If a weight shift is detected, the vacuum seals must be verified. The effect must persist in a total vacuum to prove it is not caused by atmospheric wind currents generated by the disk's rotation.
2. The Magnetic Control: The test mass must be swapped between varying non-magnetic materials like Pyrex glass, high-purity copper, and organic carbon. If the weight shift changes based on the material, it is an electromagnetic artifact. If the weight shift remains uniform regardless of the material, it is a true gravitational distortion.
